HTTP **401**. `type`: `https://docs.xebra.exchange/errors/unauthorized`

## What it means

The API key sent in `Authorization: Bearer ...` was not accepted.

## What to do

Check the key, and that it has not been revoked. Only requests that send an `Authorization` header
are refused: a request with no key at all runs at the anonymous limit instead.

A revoked key stops working within a minute, so a `401` on a key that worked a moment ago can be
revocation rather than a typo.

<Callout title="Key formats">
  A key is `xk_live_` followed by 32 letters and digits. See [API keys](/docs/guides/api-keys).
</Callout>

## Example

```json
{
  "type": "https://docs.xebra.exchange/errors/unauthorized",
  "title": "Unauthorized",
  "status": 401,
  "detail": "…",
  "code": "unauthorized"
}
```

Every error has this shape. See [Errors](/docs/errors) for how to handle them.
